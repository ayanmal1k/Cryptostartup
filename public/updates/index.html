Problems found along the way

None of these were in the feedback

  • Two-factor login was completely broken. The code read one set of database columns while the table had another. Switching 2FA on would have crashed login for that account.
  • A deposit page took no payment. It reported “Successfully deposited $X” without charging anything. Now routed to the real Stripe and PayPal flow.
  • Price charts were invented. Token sparklines drew random shapes — on assets people spend money on. They now plot real recorded history, or a flat line when there is none.
  • The desktop menu and search did nothing. Both buttons were visible, but the panel they open was force-hidden on desktop.
  • Marketplace search and sorting were decorative. The controls existed; nothing behind them read the values.

Two things to action

Demo content is on the live site. Ten sample videos and seven challenges, all clearly labelled as samples. Remove them before real users arrive with php artisan sample:videos --purge --files and php artisan sample:challenges --purge.

Deploys currently need a VPN. The host's firewall is blocking our whole IP range from SSH, FTP and cPanel, though the website itself is unaffected. Worth asking GoDaddy to lift the block on 202.63.209.0/24.
